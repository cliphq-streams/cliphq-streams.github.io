# ClipHQ website (GitHub Pages)

Static site: homepage, privacy policy, terms of service, and the OAuth callback page for clipforge.

- `callback.html` shows the `code` from TikTok/Google redirects so it can be pasted into `scripts/tiktok_auth.py`.
- Replace `{{CONTACT_EMAIL}}` everywhere with the ClipHQ contact email before publishing.
- Published at `https://<github-username>.github.io/` when the repo is named `<github-username>.github.io`.
